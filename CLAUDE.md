## Design Context

This is FitPro — a weekly meal + workout planner that generates a matched plan from the user's goals (not a logging tool). Register: `product`. Platform: `adaptive` (React Native/Expo, iOS + Android from one codebase; currently one Apple-flavored visual language with a solid fallback on Android — genuine Material 3 adaptation is a stated future goal, not yet built). Brand personality: warm, motivating, approachable — an in-house coach, not a clinical calculator or a data-logging tool.

Full strategic context: `PRODUCT.md`. Full visual system (colors, typography, motion, components — "Warm Glass"): `DESIGN.md`.
